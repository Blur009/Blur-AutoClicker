# Blur Auto Clicker 한국어 번역판

이 저장소는 [Blur009/Blur-AutoClicker](https://github.com/Blur009/Blur-AutoClicker)를 기반으로 사용자 인터페이스와 안내 문구를 한국어로 번역한 커뮤니티 버전입니다.

원본 프로젝트의 기능과 라이선스를 존중하며, 한국어 사용자가 설치·설정·실행 과정을 쉽게 이해할 수 있도록 번역에 집중했습니다.

## 한국어화 범위

- 간단 모드와 고급 모드의 주요 조작 화면
- 설정 화면의 일반, 동작, 외관, 단축키, 프로세스, 프리셋, 유지 관리 항목
- 클릭 지점, 중지 영역, 오버레이, 트레이 메뉴와 오류 안내
- 변경 기록과 프리셋 관련 버튼·상태·요약 문구
- 기존 설정에 저장된 `Standard Clicking`, `Rapid Fire`, `Precision Mode` 프리셋 이름의 자동 한국어 보정
- 프리셋 요약의 마우스 버튼과 시간 단위 한국어 표시

## 다운로드

배포 파일은 [Releases](../../releases)에서 제공합니다.

포터블판은 압축을 푼 뒤 `BlurAutoClicker.exe`를 실행하면 됩니다. 설치 과정은 필요하지 않지만 Windows WebView2 Runtime이 필요할 수 있습니다.

설정과 통계는 `%APPDATA%\BlurAutoClicker`에 저장됩니다.

## 직접 빌드

개발 환경과 빌드 방법은 [한국어 빌드 안내](BUILDING-KO.md)를 참고하세요. 번역 변경 기록은 [CHANGELOG.ko.md](CHANGELOG.ko.md)에 정리되어 있습니다.

## 원본 프로젝트와의 관계

이 저장소는 원본 프로젝트의 한국어 번역 및 한국어권 사용자용 배포 편의를 위한 변경을 담은 포크입니다. 원본 프로젝트의 저작권과 기여자 표기를 유지하며, 원본 프로젝트에 반영을 요청할 변경은 별도의 Pull Request로 제안할 수 있습니다.
